## [0.1.0] - 2026-09-30

### Added
- Project scaffolding: uv, ruff, pytest, GitHub Actions CI.
- `metrics` module: MAE, RMSE, sMAPE, rMAE, pinball loss, CRPS from quantiles,
  interval coverage and width, multivariate one-sided Diebold-Mariano test.
